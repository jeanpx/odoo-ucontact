Conexión a Odoo

Configura tu Odoo para buscar contactos automáticamente al recibir llamadas o al escribir un número en uContact.

Autenticación

Usa tu usuario y contraseña de Odoo, o genera una API Key en Odoo → Ajustes → Usuarios → tu usuario → API Key.

Si pones API Key, se usa en lugar de la contraseña. Genérala en Odoo → Ajustes → Usuarios.

Campos a mostrar en el popup

Información del contacto que se muestra al recibir o marcar una llamada.
